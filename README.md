# نظام الثقة - Altheka Drivers

نظام متكامل لإدارة طلبات المندوبين والمبيعات

## طريقة التشغيل

1. تثبيت المتطلبات:
   pip install -r requirements.txt

2. تشغيل النظام:
   python app.py

3. فتح المتصفح على:
   http://localhost:5000

## بيانات الدخول

- المدير: admin / admin123
- المندوب: حسب الكود وكلمة المرور المسجلة

## المميزات

- لوحة تحكم إدارية كاملة
- نظام متكامل للمندوبين
- إدارة الطلبات والمبيعات
- تقارير متقدمة
- واجهة عربية بالكامل
